## ⚡ À Propos

**SECURE_PASS_GEN** est un outil web conçu pour générer des mots de passe robustes tout en offrant une expérience visuelle immersive. Contrairement aux générateurs classiques, celui-ci met l'accent sur la **sécurité côté client** (Client-Side Only) et une interface utilisateur inspirée des terminaux de hacking.

### 🛡️ Pourquoi l'utiliser ?
* **100% Local :** Aucun mot de passe ne transite par un serveur. Tout est calculé dans votre navigateur via JavaScript.
* **Personnalisable :** Choix de la longueur, majuscules, symboles, chiffres.
* **Feedback Visuel :** Indicateur de force en temps réel et alertes visuelles.

---

## 💾 Fonctionnalités Clés

- [x] **Algorithme Aléatoire :** Utilisation de `Math.random()` combiné à un mélangeur de tableau (Shuffle).
- [x] **Design Immersif :** - Animation d'arrière-plan "Matrix Rain" (Canvas JS).
  - Effet CRT / Scanlines (CSS pur).
  - Typographie Monospace "Share Tech Mono".
- [x] **UX Réactive :**
  - Copie dans le presse-papier en un clic.
  - Indicateur de sécurité colorimétrique (Rouge > Orange > Vert).
  - Input clamping (limitation intelligente des valeurs entrées).
- [x] **Responsive :** Adapté aux mobiles et desktops.

## 🛠️ Installation & Utilisation

Si vous souhaitez cloner ce projet pour le modifier localement :

```bash
# 1. Clonez le dépôt
git clone [https://github.com/Goken-0/secure_pass_gen.git](https://github.com/Goken-0/secure_pass_gen.git)

# 2. Entrez dans le dossier
cd secure_pass_gen

# 3. Ouvrez index.html dans votre navigateur
# (Double-cliquez simplement sur le fichier)
```
